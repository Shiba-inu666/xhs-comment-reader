# 小红书评论读取器

[简体中文](README.md) · [English](README_EN.md)

把一篇小红书笔记里已经加载出来的评论收进浏览器侧栏，顺手看一眼评论区的 IP 属地分布。

我做这个扩展，是因为有时只想把评论复制下来，或者快速看看讨论来自哪些地区，不想为此启动爬虫、配置 Cookie 或跑一套后端服务。它是一个很小的 Chrome / Edge 扩展：打开笔记，点一下按钮，当前页面里的评论就会出现在右侧栏。

这里说的“抓取”只是读取页面已经显示出来的内容。扩展不会拦截小红书接口，也不会替你自动滚动页面。

## 能做什么

- 读取当前页面已经加载的评论
- 一键复制全部评论，每条一行
- 按页面展示的 IP 属地生成饼图
- 页面继续加载评论时自动更新侧栏
- 小红书改版导致选择器失效时，用一条可见评论重新校准
- 可选：把评论交给你自己的 DeepSeek 兼容接口做总结或舆情分析

当前版本：`v0.1.11`

## 安装

1. 点击 GitHub 页面右上方的 `Code` → `Download ZIP`，下载后解压。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的项目目录。

安装后打开一篇小红书笔记，点击扩展图标，右侧栏就会出现。

更详细的步骤见 [安装与使用指南](docs/INSTALLATION.md)。

## 怎么用

1. 打开一篇小红书笔记，确认评论区已经出现在页面上。
2. 打开扩展侧栏，点击“开始检测并读取评论”。
3. 需要更多评论时，手动向下滚动评论区。
4. 回到侧栏复制评论，或查看 IP 属地饼图。

侧栏每秒检查一次页面。只要小红书把新评论加载到了页面里，它们就会跟着出现。

## 关于评论数量

扩展读到的是页面当前已经加载的评论，不一定等于笔记显示的评论总数。小红书没有加载出来的内容，扩展也看不到。

读取时会忽略相邻且正文完全相同的重复项。隔开后再次出现的同一段文字会保留，避免误删不同位置的真实评论。

## 关于 IP 属地

这里统计的是小红书页面公开展示的“IP 属地”标签，**不是真实 IP 地址**。

评论数量、评论列表和属地饼图使用同一批评论记录。页面没有显示属地的评论会归到“未显示”；地区超过八个时，较小的分组会合并为“其他”。属地统计只留在当前侧栏内存里，不保存、不关联昵称，也不会发给外部 AI。

## AI 总结是可选的

不配置 API，也能正常读取、复制评论和查看属地分布。

如果需要总结，在侧栏底部展开“设置与自动校准” → “外部 AI API 设置”，填入自己的接口地址、模型和 API Key。扩展默认使用 DeepSeek Chat Completions 格式，提供两种输出：

- 评论区总结：概括大家在聊什么
- 舆情报告：整理情感、议题、诉求、争议和原文证据

只有你主动点击生成按钮后，评论正文才会发送到所填接口。发送内容不包括页面 URL、Cookie、账号、页面 HTML 和 IP 属地。

API Key 保存在 `chrome.storage.session`，不会写进源码或持久化本地存储。详细配置见 [AI 配置指南](docs/AI_SETUP.md)。

## 读不到评论怎么办

小红书改版后，默认选择器可能会失效。如果侧栏连续三次没有读到评论，设置区会自动展开：

1. 从页面复制一条当前可见的完整评论。
2. 粘贴到校准输入框。
3. 点击“自动查找并使用新的 data-v 属性”。

这段评论只用于当次查找，校准完成后立即清空；扩展只保存找到的新选择器。

## 项目目录

```text
xhs-comment-reader/
├── src/                 扩展代码和侧栏页面
│   ├── background.js    打开侧栏
│   ├── sidepanel.html   页面结构
│   ├── sidepanel.css    页面样式
│   ├── sidepanel.js     评论读取与交互
│   └── ai-utils.js      AI 输入、输出和证据校验
├── tests/               自动化测试
├── scripts/             校验与打包脚本
├── docs/                使用、隐私和开发文档
├── manifest.json        浏览器扩展清单
└── VERSION              当前版本号
```

`build/` 和 `deliverables/` 是打包时生成的目录，不提交到 Git。

## 开发

需要 Node.js 20 或更高版本。运行时没有第三方依赖，不需要先执行 `npm install`。

```bash
npm test           # 运行测试
npm run validate   # 检查版本、权限、安全边界和语法
npm run package    # 生成浏览器加载目录和发布 ZIP
```

目前有 30 项自动化测试。更多说明见 [开发指南](docs/DEVELOPMENT.md)。

## 目前的限制

- 只能读取已经加载到页面里的评论。
- 不会自动滚动，也不会展开尚未显示的回复。
- 页面结构变化后可能需要重新校准。
- AI 结果只是辅助整理，仍需要人工核对。
- 仓库只保留了 `v0.1.11` 的完整代码，更早版本没有可核验的源码或 Git 历史。
