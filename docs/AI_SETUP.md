# AI 配置指南

AI 功能是可选的。只读取、复制和统计评论时，不需要配置任何 API。

## 默认配置

| 设置 | 默认值 | 可调整范围 |
| --- | --- | --- |
| API 地址 | `https://api.deepseek.com/chat/completions` | HTTPS，或本机 HTTP 地址 |
| 模型 | `deepseek-v4-flash` | 以你的服务商实际可用模型为准 |
| 最多评论数 | `200` | 1–500 |
| 每批评论数 | `30` | 5–50 |
| 输出语言 | 简体中文 | 以界面选项为准 |

## 配置步骤

1. 展开“设置与自动校准”。
2. 展开“外部 AI API 设置”。
3. 填写 Chat Completions 兼容地址。
4. 填写模型名和 API Key。
5. 调整评论数量与批量大小。
6. 点击“保存设置”。
7. 读取评论后，选择“生成评论区总结”或“生成舆情报告”。

浏览器第一次访问新的 API 域名时会请求主机权限。只有确认授权后，扩展才会发送请求。

## 两种输出有什么区别

“评论区总结”用于快速了解大家在讨论什么，包含：

- 评论区总结
- 核心观点
- 普遍关注点
- 代表性评论

“舆情报告”用于更深入的研判，包含：

- 舆情结论 / 评论区总结
- 情感态势
- 主要议题
- 高频诉求
- 争议与风险点
- 代表性评论及证据

## 会发送哪些数据

只发送经过清理和去重的评论正文，以及生成报告所需的分析指令。不会发送页面 URL、Cookie、小红书账号、请求头、页面 HTML 或 IP 属地统计。

每条评论最多发送 1,000 个字符。模型返回的评论证据会与本次输入逐字核对，找不到原文的引用不会作为有效证据展示。

## API Key 如何保存

API Key 保存在 `chrome.storage.session`，不会写入源码、发布包或 `chrome.storage.local`。通常在浏览器完全退出后会清除。

公开分发浏览器扩展时，不建议在客户端中预置正式 API Key。更稳妥的方式是使用你自己的中转服务，在服务端保存上游密钥。

## 兼容接口要求

扩展发送 DeepSeek / OpenAI-compatible Chat Completions 请求，兼容接口至少应返回：

```json
{
  "choices": [
    {
      "message": {
        "content": "模型输出文本"
      }
    }
  ]
}
```

模型需要支持 JSON 对象输出。解析器也兼容部分 Responses API 文本字段，但发送格式固定为 Chat Completions。
