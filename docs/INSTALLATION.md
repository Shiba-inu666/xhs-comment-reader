# 安装与使用指南

这份文档面向第一次手动安装浏览器扩展的用户。

## 安装前准备

- Chrome 116 或更高版本，或者支持 Manifest V3 的新版 Edge。
- 已下载并解压本项目。
- 解压后的目录中能够看到 `manifest.json`。

## 在 Chrome 中安装

1. 在地址栏输入 `chrome://extensions` 并回车。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目根目录。
5. 扩展列表中出现“小红书评论读取器（极简版）”即表示安装成功。

## 在 Edge 中安装

步骤与 Chrome 相同，只需把扩展管理地址改成 `edge://extensions`。

## 读取评论

1. 打开一篇小红书笔记。
2. 确认页面中至少显示了一条评论。
3. 点击浏览器工具栏中的扩展图标。
4. 在右侧栏点击“开始检测并读取评论”。
5. 查看评论数、评论列表与 IP 属地分布。

扩展每秒检查一次当前页面。你手动向下滚动并加载更多评论后，新增评论会自动出现在侧边栏中。

## 复制评论

读取到评论后，“一键复制全部评论”按钮会自动启用。复制结果保持当前页面顺序，每条评论占一行。

## 默认选择器失效怎么办

如果连续三次没有匹配到评论，“设置与自动校准”会自动展开：

1. 从小红书页面复制一条当前可见的完整评论。
2. 粘贴到校准输入框。
3. 点击“自动查找并使用新的 data-v 属性”。
4. 校准成功后再次读取评论。

粘贴的评论只用于本次查找，不会保存。扩展只保存校准后得到的选择器。

## 更新本地版本

如果扩展加载的是项目根目录，更新代码后可以在扩展管理页点击刷新按钮。

如果加载的是 `build/unpacked`，先在项目目录运行：

```bash
npm run package
```

然后点击侧边栏底部的“应用本地更新并重载扩展”，或在扩展管理页点击刷新按钮。

## 常见问题

### 为什么评论数少于页面总评论数？

扩展只读取浏览器当前已经加载到 DOM 中的评论。请手动向下滚动，等待小红书加载更多评论。

### 为什么没有 IP 属地？

只有页面中已经显示属地标签的评论才有明确属地；其余评论会归入“未显示”。

### 为什么 AI 按钮不可用？

请先读取评论，再到“外部 AI API 设置”中填写并保存可用的 API 配置。

### 卸载后数据还在吗？

浏览器通常会在卸载扩展时删除该扩展的本地存储。你也可以先在设置中清除 API Key。
