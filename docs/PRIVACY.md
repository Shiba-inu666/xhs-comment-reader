# 隐私与安全说明

## 本地读取

扩展只在用户当前打开的小红书标签页中读取已经显示的评论文本和属地标签。评论保存在侧边栏运行时内存中，不写入本地数据库。

## 本地保存

`chrome.storage.local` 只保存：

- 评论选择器
- AI API 地址
- 模型名
- 批量大小、最多评论数和输出语言

`chrome.storage.session` 只保存：

- 用户填写的 API Bearer Token

校准时粘贴的评论、读取到的评论、IP 属地统计和 AI 输出均不持久化。

## 外部请求

只有用户主动点击“生成评论区总结”或“生成舆情报告”后，扩展才会向用户配置的 API 地址发起请求。

请求数据包括：

- 去重后的评论正文
- 分析任务说明
- 用户设置的输出语言

请求数据不包括：

- 当前页面 URL 或笔记 ID
- Cookie、账号和登录凭据
- 页面 HTML、请求头或网络响应
- IP 属地统计

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 在浏览器右侧显示扩展界面 |
| `scripting` | 在当前小红书标签页读取可见评论 DOM |
| `storage` | 保存非敏感设置和会话级 API Key |
| 小红书主机权限 | 限定评论读取范围 |
| 可选 API 主机权限 | 用户生成 AI 内容时访问其填写的接口 |

## 明确不做的事情

- 不监听或拦截小红书网络请求
- 不读取 Cookie 或登录令牌
- 不自动滚动、点击或翻页
- 不采集昵称与账号资料
- 不添加遥测或行为追踪
- 不从远程加载可执行代码

使用外部 AI 前，请确认 API 地址属于你信任的服务商，并了解其费用和数据处理政策。
